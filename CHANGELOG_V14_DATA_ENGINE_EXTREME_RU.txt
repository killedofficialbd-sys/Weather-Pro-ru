WEATHER PRO V14 — DATA ENGINE EXTREME

НОВЫЕ ФУНКЦИИ DATA ENGINE
- Advanced Data Lab с глубоким аудитом целостности текущих наблюдений и прогноза.
- Контроль физических диапазонов значений, времени наблюдения, порядка временных меток, дубликатов, пропусков и резких скачков температуры.
- Сравнение OpenWeather и Open-Meteo по текущей температуре, влажности и скорости ветра с учётом различий источников.
- Performance Lab: три независимых сетевых запроса с медианной задержкой, максимальным откликом и джиттером.
- Локальный JavaScript micro-benchmark; не выдаётся за измерение физической загрузки CPU или RAM.
- Forecast Verification: локальное сохранение точек прогноза и последующее сопоставление с фактическими наблюдениями; расчёт MAE по доступным совпадениям.
- Cache Manager: оценка количества/объёма записей, обнаружение просроченного кэша, резервное копирование и восстановление только погодного кэша.
- Безопасная очистка только просроченных записей погодного кэша после подтверждения.
- PWA update check: запрос обновления Service Worker без автоматической активации и принудительной перезагрузки.
- Permission Inspector: чтение поддерживаемых статусов разрешений без вызова системных запросов.
- Runtime Error Journal: локальная фиксация window.error и unhandledrejection.
- Опциональный foreground auto-monitor с интервалом 5/15/30 минут; работает только при открытом видимом разделе Data Engine.
- Полный JSON и автономный HTML-отчёт.
- Схема data lineage и расширенная сводка.

БЕЗОПАСНОСТЬ И ОГРАНИЧЕНИЯ
- Сравнение провайдеров и сетевой бенчмарк запускаются только по явному нажатию.
- Автоконтроль выключен по умолчанию.
- В отчёты не включаются API-ключи, токены, UID, email и содержимое Firebase-документов.
- Firebase SDK и Firestore Rules не изменены; личные Firestore-документы не читаются.
- Импорт принимает только проверенные записи погодного кэша; остальные LocalStorage-ключи не затрагиваются.
- Нельзя достоверно прочитать реальные квоты API-провайдеров, физический CPU/RAM или закрытое содержимое аккаунта только из браузера.
- Достоверность Forecast Verification зависит от того, как часто приложение обновляется и сохраняет прогнозы и наблюдения.

СОХРАНЕНО
- Погодный интерфейс V12, реалистичная атмосфера, карты, прогнозы и прежние разделы.
- Все существующие Firebase настройки и Firestore Rules.
- storage.rules не добавлялся.
