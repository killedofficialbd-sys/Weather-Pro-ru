Weather Pro V8.2 — исправление страницы уведомлений

1. Убраны обращения к users/{uid}/notifications из browser-only версии.
   В текущем проекте нет серверного отправителя, а Firestore Rules не открывают эту
   подколлекцию. Именно эти запросы приводили к PERMISSION_DENIED и сообщению
   «Не удалось обновить уведомления». История уведомлений этой версии хранится локально
   в браузере отдельно для каждого вошедшего пользователя.
2. Кнопка «Отметить всё прочитанным» теперь обновляет локальную историю и не выполняет
   недоступный Firestore batch-запрос.
3. Первичный snapshot сообщений используется только как исходная точка: старые сообщения
   не превращаются в новые уведомления после перезагрузки страницы.
4. При открытии чата связанные локальные уведомления помечаются прочитанными.
5. Исправлено точечное сохранение курсора прочтения одного чата без перезаписи курсоров
   остальных диалогов.
6. Возвращён синий значок сообщения; убран красный badge с глобуса нижней навигации.
7. Обновлены URL версий CSS/JS и версия кеша Service Worker, чтобы старый код не оставался
   в телефоне после обновления сайта.

Ограничение: локальная история не синхронизируется между устройствами. Настоящие push при
полностью закрытом сайте требуют доступного серверного отправителя; эта версия работает
без Cloud Functions и платного Firebase тарифа, пока сайт открыт или работает в фоне.
