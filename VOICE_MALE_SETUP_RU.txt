WEATHER PRO V8 — МУЖСКАЯ ОЗВУЧКА

Кнопки «Озвучить погоду» и «Озвучить сводку» теперь сначала используют мужской голос TTS.ai (предпочтительно Denis / Piper для русского языка). API-ключ не нужен для анонимного бесплатного режима.

Ограничения: сервис TTS.ai указывает лимиты бесплатного режима (до 500 символов на запрос; дневные/почасовые лимиты могут меняться). Приложение запрашивает голос при первом запуске озвучки, затем кеширует ID голоса в localStorage. Если сервис недоступен, исчерпан лимит или браузер не может воспроизвести MP3, используется системный голос устройства с попыткой выбрать мужской голос и пониженным pitch.

Важно: TTS.ai получает текст погодной сводки для генерации аудио. Голос Denis (Piper) обозначен поставщиком как бесплатный только для личного некоммерческого использования. Не используйте его в коммерческом продукте без отдельной лицензии.

Никакой API-ключ не добавлен в клиентский код. Подключение работает с GitHub Pages и не требует Firebase Functions, Termux, npm или отдельного деплоя.
