WEATHER PRO V8.4 — МУЖСКАЯ ОЗВУЧКА ПОГОДЫ

- Заменена стандартная женская/неопределённая браузерная озвучка на мужской русский голос Denis (Piper) через бесплатный TTS.ai API.
- Для выбора голоса приложение динамически получает каталог мужских голосов; голос Denis предпочитается для русского языка.
- Для английского языка выбирается доступный мужской голос из каталога.
- API-ключ не требуется для анонимного бесплатного режима; действуют лимиты поставщика.
- Добавлен системный резервный TTS с выбором мужского голоса по имени и пониженным тоном.
- Добавлена остановка/переключение озвучки повторным нажатием.
- Обновлена версия кеша Service Worker для получения нового index.html.

Примечание: мужской голос Denis (Piper) в каталоге TTS.ai помечен как бесплатный для личного некоммерческого использования. Текст сводки отправляется сервису TTS.ai для генерации аудио. Если сервис недоступен или исчерпан бесплатный лимит, используется системная озвучка устройства.
