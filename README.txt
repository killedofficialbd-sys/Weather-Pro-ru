WEATHER PRO 10.1.1 — SMART DEVICE ULTIMATE

Основа: Weather Pro 10.0.6. Сохранены погодные функции, Firebase Auth/Firestore, профиль с заблокированным email, Firestore rules, PWA, Device Engine MAX и исправления прокрутки Data Engine.

НОВОЕ В 10.1:
- Battery Intelligence: локальная история доступного уровня заряда (только при поддержке Battery API; события заряда и периодический замер при открытой вкладке).
- Advanced Benchmark: сохранение и сравнение истории JS/Canvas тестов.
- Security Center: базовая проверка secure context, CSP meta, Permissions API, localStorage, Service Worker и статуса Firebase Auth. Это не аудит серверной конфигурации.
- Usage Analytics: длительность текущей сессии и число запусков Weather Pro в этом браузере; не видит использование других приложений.
- Smart Device Report: экспорт JSON без auth токенов, email и raw media.
- Device Lab Map: интерактивные переходы к тестам батареи, экрана, камеры, touch и аудио.
- Automatic Diagnostics: последовательный запуск доступных проверок.

ПРИВАТНОСТЬ И ОГРАНИЧЕНИЯ:
Все новые данные хранятся локально в браузере. Экспорт запускается вручную. Браузер не предоставляет точную температуру/здоровье батареи, физическую RAM, IMEI, системную статистику использования приложений или полноценные hardware diagnostics. Для камеры/микрофона требуются HTTPS и отдельное разрешение.

FIREBASE:
Используйте приложенные rules.txt для Firestore Rules. Email в профиле остаётся read-only и серверные правила должны быть опубликованы в Firebase Console.

ПРОВЕРКИ:
HTML и встроенные JavaScript блоки проверены синтаксически; ZIP проверен на целостность. Реальное тестирование на физическом Android и production Firebase не выполнялось.


ВИЗУАЛЬНОЕ ОБНОВЛЕНИЕ 10.1.1:
- Все значки Device Lab и статусов новых модулей используют Font Awesome вместо эмодзи/текстовых символов.
- В Usage Analytics подписи и значения вынесены в отдельные компактные карточки с отступами; адаптировано для узких экранов.
- Обновлён номер кеша Service Worker для доставки новой версии установленной PWA.
