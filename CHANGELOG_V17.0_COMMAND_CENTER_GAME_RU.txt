WEATHER PRO V17.0 — COMMAND CENTER + STORM RUNNER
=================================================

1. Добавлен отдельный экран Command Center с клиентской диагностикой:
   - JavaScript runtime;
   - Firebase SDK и состояние активной авторизации;
   - готовность клиентского Firestore SDK;
   - статус соединения браузера;
   - поддержка Service Worker / PWA;
   - доступность LocalStorage;
   - наличие последних погодных данных.
2. Добавлен экспорт отчёта Command Center в JSON. В отчёт не включаются email,
   UID, токены, содержимое профиля или личные документы Firestore.
3. Добавлен визуальный значок «Основатель Weather Pro» для активной Firebase-сессии
   с email killedofficialbd@gmail.com. Значок вычисляется только по email текущего
   пользователя Firebase Auth, а не по изменяемому тексту профиля или кэшу.
   Значок показывается в личном профиле активной сессии. Это визуальная отметка интерфейса,
   не механизм выдачи административных прав и не изменение publicProfiles / Firestore Rules.
4. Добавлена встроенная 2D-аркада Storm Runner:
   - управление клавишами A/D, стрелками и сенсорными кнопками;
   - препятствия-молнии и собираемые энергетические сферы;
   - счёт, время, лучший результат и сохранение рекорда локально;
   - пауза, сброс и повторный запуск.
5. Новые CSS/JS-файлы подключены как обычные статические веб-ресурсы.
6. Service Worker cache version обновлён, новые файлы добавлены в офлайн-shell.

Требования: HTML/CSS/JavaScript и существующий Firebase Web SDK. Node.js, npm,
сборка и серверные функции для Command Center и Storm Runner не нужны.

Существующие страницы и функции V16.2.2 не удалялись. Firestore rules и publicProfiles
не изменялись. Новые функции не создают и не изменяют документы Firebase.
