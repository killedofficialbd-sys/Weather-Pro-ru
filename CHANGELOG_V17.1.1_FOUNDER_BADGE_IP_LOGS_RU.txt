WEATHER PRO V17.1.1 — ИСПРАВЛЕНИЕ ЗНАЧКА ОСНОВАТЕЛЯ И IP-ЖУРНАЛА

1. Исправлено отображение значка «ОСНОВАТЕЛЬ WEATHER PRO». Ранее CSS display:inline-flex переопределял HTML hidden, поэтому значок мог отображаться у всех аккаунтов. Добавлено явное правило [hidden]{display:none!important}.
2. Проверка владельца привязана только к подтверждённому Firebase Auth currentUser после первого auth-state callback. Кэш профиля и устаревший fbUser не используются как доказательство личности.
3. Значок и ссылка в админ-панель синхронизируются после изменения состояния Firebase Auth.
4. Добавлен публичный компактный значок рядом с основателем в результатах поиска, списке друзей, списке диалогов, заголовке личного чата и сообщениях. Он строится по email из publicProfiles, который по действующим Firestore Rules должен совпадать с Firebase Auth.
5. Улучшен локальный CSV-просмотр IP-журналов: запятая, точка с запятой и табуляция; поддержаны распространённые названия полей Cloudflare/access-логов (например ClientIP, ClientRequestURI, EdgeResponseStatus).
6. IP-файл по-прежнему обрабатывается только в браузере администратора и не загружается в Firebase. Статический сайт не получает IP других посетителей автоматически; связь IP с Firebase UID/email возможна только если такие поля действительно присутствуют в выгрузке.
7. Обновлена версия Service Worker, чтобы браузеры получили исправленные CSS/JS без старого PWA-кэша.

Firebase Rules и блок publicProfiles не изменялись. Node.js, npm, package.json и серверная часть не добавлялись.
