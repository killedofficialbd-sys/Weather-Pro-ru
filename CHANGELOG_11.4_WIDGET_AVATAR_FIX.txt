WEATHER PRO 11.4 — NATIVE ANDROID WIDGET + FULL AVATAR RENDERING

АВАТАРЫ
- Отображение аватаров переведено с CSS background-image на настоящие img-элементы.
- Для фото включён object-fit: contain и центральное позиционирование; портретные и широкие снимки не обрезаются.
- Сжатие больше не превращает фотографию в квадрат и не добавляет размытый дубликат по краям.
- Исходное соотношение сторон сохраняется; длинная сторона сжимается максимум до 640 px.
- Исправление применяется к аватару шапки, личному профилю, предпросмотру, поиску пользователей и спискам друзей/чатов.
- Изображения, уже сохранённые в старом квадратном формате, невозможно восстановить из потерянного оригинала. Чтобы получить исходное кадрирование без старой подложки, один раз загрузите оригинал заново.

ANDROID HOME-SCREEN WIDGET
- Добавлен отдельный Android Studio-проект android-widget-app с настоящим AppWidgetProvider.
- Виджет показывает город, температуру, описание погоды, погодный символ, ветер и влажность.
- Погодные данные запрашиваются у Open-Meteo; отдельный ключ не требуется.
- Для каждого экземпляра виджета можно задать свой город.
- Добавлена ручная кнопка обновления, настройка города и необязательная ссылка на размещённый сайт Weather Pro.
- Для системного обновления установлен период 30 минут; фактическое выполнение может откладываться Android.
- В существующую страницу «Виджет» добавлена инструкция сборки и размещения настоящего Android AppWidget.

ОГРАНИЧЕНИЕ СБОРКИ
- В рабочей среде отсутствует Android SDK и Gradle, поэтому APK здесь не собирался.
- В архиве лежит исходный Android Studio-проект; APK собирается локально в Android Studio.
- Непрерывная CSS-анимация недоступна для обычного системного Android AppWidget на RemoteViews. Значок и данные меняются при обновлении погоды; Android Launcher применяет системный переход между обновлёнными представлениями. Частые кадровые обновления не запускаются ради экономии батареи.

ПРОВЕРКИ
- Проверен синтаксис встроенного JavaScript.
- Проверена структура AndroidManifest.xml, XML ресурсов и Gradle Kotlin DSL на базовую целостность.
- Проверена целостность итогового ZIP.
- Реальная работа Open-Meteo и установка на физический телефон требуют сборки APK и проверки на устройстве.
